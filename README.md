# 🪟 Super-Win

### Маленькие утилиты, которых не хватает Windows каждый день

**Правильный выделяльщик** — лёгкое приложение в трее. Висит тихо, ест почти ноль ресурсов и добавляет в систему четыре вещи, по которым давно плачет каждый, кто видел macOS.

Выделил текст → получил готовый файл. Навёл на окно → закрепил поверх всех. Не можешь скопировать текст с картинки → выделил область, и он в буфере. Хочешь глянуть файл → пробел.

## ✨ Что умеет

### 📝 Текст → готовый документ, прямо в чат

Выдели любой текст в любом приложении — рядом всплывает компактная панель `MD · PDF · DOCX`. Жмёшь формат — и файл **уже в буфере обмена**. Заходишь в Telegram, Discord, Outlook, Word — `Ctrl+V`, и вставляется **сам файл**, а не текст.

> Под капотом — буфер формата `CF_HDROP` (тот же, что у «Копировать» в Проводнике). Поэтому файл принимает любое приложение, куда можно перетащить документ.

Текст разбирается в «умный Markdown»: заголовки, списки, код — и одинаково аккуратно рендерится во все три формата.

---

### 📌 Закрепить окно поверх всех — `Ctrl+Alt+T`

Одно приложение на весь экран, второе — маленькое, и хочется, чтобы оно **не пряталось**. Навёл на нужное окно, нажал `Ctrl+Alt+T` — оно висит сверху, как закреп. Нажал ещё раз — снял.

> Работает поверх полноэкранных borderless-приложений, видео и браузеров. Эксклюзивный fullscreen у некоторых игр перебить нельзя — это ограничение Windows.

---

### 🔤 OCR области экрана — `Ctrl+Alt+O`

Текст на картинке, в видео, в PDF-сканах — то, что «нельзя выделить». Жмёшь `Ctrl+Alt+O`, выделяешь прямоугольник — **распознанный текст уже в буфере**. `Ctrl+V` куда угодно.

> Движок — встроенный в Windows `Windows.Media.Ocr`. Полностью офлайн, поддерживает русский и английский (по установленным языковым пакетам ОС). Ничего никуда не отправляется.

---

### 👁 Быстрое превью файла — `Пробел`

Как Quick Look на Mac. В Проводнике выделил файл, нажал `Пробел` — мгновенное превью. `Пробел` или `Esc` — закрыть.

| Тип | Что показывает |
|-----|----------------|
| 📄 Текст / код | моноширинный, до 1 МБ |
| 🖼 Картинки | png, jpg, gif, bmp, webp, … |
| 📕 PDF | постраничный рендер |
| 🎬 Видео | mp4, mkv, mov, webm — с автоплеем |

> `Пробел` перехватывается **только** в окне Проводника с выбранным файлом. В остальных местах пробел работает как обычно — набор текста нигде не ломается.

## ⌨️ Горячие клавиши

| Действие | Клавиши |
|----------|---------|
| Документ из выделенного текста | панель у курсора → `MD` / `PDF` / `DOCX` |
| Закрепить / открепить окно | `Ctrl+Alt+T` |
| OCR области экрана | `Ctrl+Alt+O` |
| Превью файла в Проводнике | `Пробел` |
| Закрыть превью | `Пробел` / `Esc` |

Всё остальное — иконка в трее: настройки, вкл/выкл, выход.

## 🚀 Установка

1. Скачай **`PravVyd.exe`** из [Releases](https://github.com/Artem-Levchenko-hub/Super-Win/releases) (один файл, ~88 МБ, всё внутри).
2. Запусти. **.NET ставить не надо** — рантайм вшит.
3. SmartScreen ругнётся «Неизвестный издатель» (приложение не подписано) → **Подробнее → Выполнить в любом случае**.
4. Появится иконка в трее. Готово.

> Windows 10 (1809+) / 11, 64-бит. Первый запуск чуть медленнее — распаковка во временную папку.

## 🛠 Сборка из исходников

```powershell
git clone https://github.com/Artem-Levchenko-hub/Super-Win.git
cd Super-Win

# запустить
dotnet run --project PravVyd

# собрать один self-contained .exe
dotnet publish PravVyd/PravVyd.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true
```

Готовый `.exe` появится в `PravVyd/bin/Release/net8.0-windows10.0.19041.0/win-x64/publish/`.

## 🧱 Стек и архитектура

| Слой | Чем сделано |
|------|-------------|
| UI | WPF (.NET 8), панель / окна без рамок, иконка в трее (WinForms `NotifyIcon`) |
| Документы | свой парсер текста → модель → 3 writer'а (`MarkdownWriter`, `PdfWriter` на **QuestPDF**, `DocxWriter` на **OpenXML**) |
| OCR | `Windows.Media.Ocr` (WinRT) |
| Превью PDF | `Windows.Data.Pdf` (WinRT) |
| Системное | `user32` P/Invoke: глобальные хоткеи, low-level mouse/keyboard hooks, topmost, буфер `CF_HDROP` |

Код разложен по слоям: `Documents/` (чистая логика, без UI), `Infrastructure/` (Win32, буфер, хоткеи, захват), `Services/` (оркестрация), `Ui/` (окна, трей). P/Invoke спрятан за `NativeMethods` и не торчит наружу.

## ⚠️ Честные ограничения

- Приложение **не подписано** → разовое предупреждение SmartScreen.
- OCR использует языковые пакеты Windows. Нет нужного языка → *Параметры → Время и язык → Язык → Языковые компоненты → Распознавание текста*.
- Закреп не работает поверх **эксклюзивного** fullscreen (часть игр) — ограничение Windows.
- Видео-превью зависит от системных кодеков (Media Foundation).
