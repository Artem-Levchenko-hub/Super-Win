# 🪟 Super-Win

### Маленькие утилиты, которых не хватает Windows каждый день

**Правильный выделяльщик** — лёгкое приложение в трее. Висит тихо, ест почти ноль ресурсов и добавляет в систему **восемь** вещей, по которым давно плачет каждый, кто видел macOS.

<br/>

`MD/PDF/DOCX` • `Закреп поверх` • `OCR экрана` • `Quick Look` • `Вернуть папку` • `Полка` • `Раскладка` • `Авто-раскладка`

## ⌨️ Все горячие клавиши (шпаргалка)

| Действие | Клавиши |
|----------|---------|
| Документ из выделенного текста | выдели текст → панель → `MD` / `PDF` / `DOCX` |
| Закрепить / открепить окно поверх всех | `Ctrl + Alt + T` |
| OCR — распознать текст с области экрана | `Ctrl + Alt + O` |
| Превью файла **или папки** в Проводнике (удерживай) | `Пробел` |
| Вернуть последнюю закрытую папку | `Ctrl + Shift + T` |
| Исправить раскладку выделенного текста | `Ctrl + Alt + R` |
| Авто-исправление раскладки по словарю (обе стороны) | само, на `Пробел` |
| Полка для файлов | панель у правого края экрана |

## ✨ Что умеет — подробно

### 📝 Текст → готовый документ, прямо в чат

Выдели любой текст в любом приложении — рядом всплывает компактная панель `MD · PDF · DOCX`. Жмёшь формат — файл **уже в буфере обмена**. Заходишь в Telegram, Discord, Outlook, Word → `Ctrl+V`, и вставляется **сам файл**, а не текст.

> Под капотом — буфер формата `CF_HDROP` (как «Копировать» у файла в Проводнике). Поэтому файл принимает любое приложение, куда можно перетащить документ.

---

### 📌 Закрепить окно поверх всех — `Ctrl+Alt+T`

Одно приложение на весь экран, второе маленькое, и нужно, чтобы оно **не пряталось**. Навёл на нужное окно, нажал `Ctrl+Alt+T` — висит сверху. Нажал ещё раз — снял.

---

### 🔤 OCR области экрана — `Ctrl+Alt+O`

Текст на картинке, в видео, в PDF-сканах. Жмёшь `Ctrl+Alt+O`, выделяешь прямоугольник — **распознанный текст уже в буфере**. `Ctrl+V` куда угодно. Движок встроен в Windows, работает офлайн (RU+EN).

---

### 👁 Быстрое превью файла — удерживай `Пробел`

Как Quick Look на Mac. В Проводнике выдели файл и **зажми `Пробел`** — превью висит поверх всех окон, пока держишь. **Отпустил — пропало.**

| Тип | Что показывает |
|-----|----------------|
| 📄 Текст / код | моноширинный, до 1 МБ |
| 🖼 Картинки | png, jpg, gif, bmp, webp, … |
| 📕 PDF | постраничный рендер |
| 🎬 Видео | mp4, mkv, mov, webm — с автоплеем |
| 📁 Папка | список вложенного: папки сверху, файлы с размерами |

> `Пробел` перехватывается **только** в окне Проводника с выбранным файлом — набор текста нигде не ломается.

---

### ↩️ Вернуть закрытую папку — `Ctrl+Shift+T`

Случайно закрыл окно Проводника? `Ctrl+Shift+T` — открывается заново. Как «вернуть вкладку» в браузере, но для папок. История на 25 шагов.

> Работает для **папок Проводника** (открытых, пока программа запущена). Закрытые окна произвольных приложений Windows восстановить нельзя — у системы нет такого API.

---

### 🗄 Полка — буфер для перетаскивания

Перетаскивать файл между окнами неудобно, когда нужное окно свёрнуто. У правого края экрана висит **полка**: перетащи файл на неё — он там полежит. Потом перетащи с полки в нужное место. `✕` на чипе убирает файл. Вкл/выкл — в трее.

---

### ⌨️ Исправить раскладку — `Ctrl+Alt+R`

Хотел по-русски, а вышло `ghbdtn`? Выдели криво-набранный текст, нажми `Ctrl+Alt+R` — переложится по позиции клавиш (QWERTY↔ЙЦУКЕН) и встанет на место. Направление определяется само.

---

### 🤖 Авто-раскладка — само, на пробеле

Как Punto Switcher: больше не думаешь, какой язык включён. Набрал слово не в той раскладке и нажал `Пробел` — программа **сама** заменит текст и переключит язык. Работает в **обе стороны**:

- `ghbdtn` + `Пробел` → **привет** (раскладка → RU)
- `руддщ` + `Пробел` → **hello** (раскладка → EN)

Решение принимается **по словарю**: внутри вшиты частотные списки EN+RU (~50 000 слов со словоформами). Меняем, только если в другой раскладке получается **реальное слово**. Если слова нет ни в одном словаре — **не трогаем** (имена, переменные, пароли остаются как есть).

> IT-термины (`sql`, `html`, `css`, `php`, `json`, …) в белом списке — не конвертируются. Переключается через трей, состояние запоминается.

## 🚀 Установка

1. Скачай **`PravVyd.exe`** из [Releases](https://github.com/Artem-Levchenko-hub/Super-Win/releases) (один файл, ~88 МБ, всё внутри).
2. Запусти. **.NET ставить не надо** — рантайм вшит.
3. SmartScreen ругнётся «Неизвестный издатель» (приложение не подписано) → **Подробнее → Выполнить в любом случае**.
4. Появится иконка в трее — там все настройки и подсказки по клавишам. Готово.

> Windows 10 (1809+) / 11, 64-бит. Первый запуск чуть медленнее — распаковка во временную папку.

## 🛠 Сборка из исходников

```powershell
git clone https://github.com/Artem-Levchenko-hub/Super-Win.git
cd Super-Win

# запустить
dotnet run --project PravVyd

# собрать один self-contained .exe
dotnet publish PravVyd/PravVyd.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true
```

Готовый `.exe` — в `PravVyd/bin/Release/net8.0-windows10.0.19041.0/win-x64/publish/`.

## 🧱 Стек и архитектура

| Слой | Чем сделано |
|------|-------------|
| UI | WPF (.NET 8): панель, превью, полка, оверлей; иконка в трее (WinForms `NotifyIcon`) |
| Документы | свой парсер текста → модель → 3 writer'а (`MarkdownWriter`, `PdfWriter` на **QuestPDF**, `DocxWriter` на **OpenXML**) |
| OCR | `Windows.Media.Ocr` (WinRT) |
| Превью PDF | `Windows.Data.Pdf` (WinRT) |
| Системное | `user32` P/Invoke: глобальные хоткеи, low-level mouse/keyboard hooks, topmost, буфер `CF_HDROP`, Shell COM |

Код разложен по слоям: `Documents/` (чистая логика без UI), `Infrastructure/` (Win32, буфер, хоткеи, захват, раскладка, OCR), `Services/` (оркестрация), `Ui/` (окна, трей). P/Invoke спрятан за `NativeMethods`, хоткеи — за общим `GlobalHotkeys`.

## ⚠️ Честные ограничения

- Приложение **не подписано** → разовое предупреждение SmartScreen.
- OCR использует языковые пакеты Windows. Нет нужного языка → *Параметры → Время и язык → Язык → Языковые компоненты → Распознавание текста*.
- Закреп не работает поверх **эксклюзивного** fullscreen (часть игр) — ограничение Windows.
- «Вернуть закрытую папку» — только окна Проводника, не произвольные приложения.
- Авто-раскладка знает топ-50k слов каждого языка: редкое слово вне словаря авто не починит (но и не сломает — оставит как есть). Ручной `Ctrl+Alt+R` работает всегда.
- Видео-превью зависит от системных кодеков (Media Foundation).
